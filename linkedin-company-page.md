### Where contact details actually live on a Company Page

LinkedIn has no public **email** field for company pages — email reaches people
via the custom button or the About text, both of which are set up above. The rest
are real fields, set in Page admin:

| Detail | Set it in | Visitors see it |
| --- | --- | --- |
| Website | Edit page → Page info | Overview sidebar + About tab |
| Phone | Edit page → Page info | About tab |
| Address | Edit page → Locations | About tab, with map link |
| Custom button | Edit page → Buttons | Header, beside Follow |

Because these fields carry the contact details permanently, **posts should not
repeat them** — that's why the two text-only posts were dropped.
